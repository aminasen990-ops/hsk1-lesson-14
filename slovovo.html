🐎 蒙古族 měng gǔ zú Монголы (один из малых народов Китая)

✏️ Прописи · 蒙古族

пиши по памяти

🧠 Суть

Название монгольского этноса, одна из официально признанных национальных меньшинств Китая.

中国少数民族之一，擅长骑马，有独特舞蹈与文化。

🎯 Как запомнить

🪝 Ассоциация

В летнем кочевом лагере на лугу люди в национальной одежде танцуют и скачут на лошадях. Это — 蒙古族.

蒙 méng：⺌(крыша) + 豕(свинья) + 冖(покрытие) — туман, покрывало.

古 gǔ：口(рот) + 十(десять) — древний, старый.

族 zú：方(знамя) + 矢(стрела) — род, народ, племя.

⚠️ Похожий иероглиф: 族 легко перепутать с 旅 lǚ (путешествие, отряд).

🧩 Мнемоника

🌫️+📜+🏹: туман + древность + племя = монгольский народ

⚠️ Ловушка: 蒙古族 ≠ 蒙古 (měng gǔ)

«蒙古» — Монголия (страна), «蒙古族» — этнос монголов в Китае. HSK проверяет разницу между народом и страной.

q: 🎯 Если написать «蒙古» вместо «蒙古族»?

a: ✅ Ты назовёшь страну, а не народность.

why: в китайском суффикс 族 обязателен для названия этноса.

mem: 族 = народ, добавляй 族 для названия народа.

👨‍👩‍👧 抚养 fǔ yǎng воспитывать, растить (детей)

✏️ Прописи · 抚养

пиши по памяти

🧠 Суть

Заботиться, кормить и воспитывать маленьких детей, обычно до их взросления.

保护、教育孩子长大，多指父母对子女。

🎯 Как запомнить

🪝 Ассоциация

Мама каждый день кормит, учит и заботится о маленьком ребёнке, пока он не вырастет. Это — 抚养.

抚 fǔ：扌✋(рука) + 无 — гладить, бережно трогать, заботиться.

养 yǎng：羊🐑 + 食🍜 — кормить, выращивать.

⚠️ Похожий иероглиф: 抚 легко перепутать с 扶 fú (поддерживать, помогать подняться).

🧩 Мнемоника

✋+🍜: бережная рука + кормить = растить и воспитывать детей

⚠️ Ловушка: 抚养 ≠ 赡养 (shàn yǎng)

抚养 — растить маленьких детей; 赡养 — содержать пожилых родителей.

q: 🎯 «содержать пожилую мать» — можно 抚养?

a: ✅ Нет, нужно 赡养.

why: направление разное: 抚养 — взрослые → дети, 赡养 — дети → пожилые родители.

mem: 抚 — для детей, 赡 — для пожилых.

🤝领养lǐng yǎng усыновить, удочерить

✏️ Прописи · 领养

пиши по памяти

🧠 Суть

Официально взять чужого ребёнка из приюта и стать его законными родителями.

合法地收下别人的孩子，当成自己的孩子养育。

🎯 Как запомнить

🪝 Ассоциация

Бездетная пара проходит все документы, берёт малыша из детского дома и воспитывает его. Это — 领养.

领 lǐng：页📄 + 令 — получить, взять по документу.

养 yǎng：羊🐑 + 食🍜 — кормить, выращивать.

⚠️ Похожий иероглиф: 领 легко перепутать с 岭 lǐng (горный хребет).

🧩 Мнемоника

📄+🍜: взять по документам + растить = усыновить

⚠️ Ловушка: 领养 ≠ 抚养 (fǔ yǎng)

领养 — официально взять ребёнка себе; 抚养 — просто растить любого ребёнка.

q: 🎯 «领养自己亲生的孩子» — можно?

a: ✅ Нет, 领养 только для приёмных детей.

why: в слове 领 есть смысл «получить, взять» ребёнка не из своей семьи.

mem: 领养 = взять чужого ребёнка по закону.
